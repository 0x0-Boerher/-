# 回转番茄罐 🍅

转动番茄罐，接受一颗番茄给你的命运，然后迅速行动起来，完成这段时间！
回转番茄罐是一款结合专注计时、项目提醒和日历记录的 Android 应用。通过转动表盘选择时间，用便签整理提醒，在日历里查看自己的专注记录。

## 下载与安装

进入本仓库的 **Releases**，展开对应版本的 **Assets**，下载 `.apk` 文件并在安卓手机上安装。
当前为测试版本。请先查看该版本的更新说明和已知问题。

## 专注计时

在专注页面的空白区域：
- **向左滑动**：选择正计时、倒计时或随机计时模式。
- **向右滑动**：选择表盘皮肤。

普通计时模式下，先转动表盘选择时间，再长按指针，展开项目并选择要专注的提醒事项。
顺时针转动增加时长，逆时针转动减少时长。计时过程中，可使用左下角的暂停和终止按钮。
随机模式下，顺时针转动扭蛋机旋钮一圈，等待番茄掉出。抽出的番茄决定本次专注时长，再选择提醒事项开始专注。

随机计时支持两种操作顺序
先选择提醒，再抽取时间：长按机器选择项目中的提醒事项，然后顺时针旋转扭蛋机按钮一圈，或向下拉动拉霸机拉杆。抽出的时长不超过提醒设置的有效安排时长。例如计划在 12:00—14:00 完成，随机时长最多为 120 分钟。抽取完成后开始该提醒的专注。
先抽取时间，再选择提醒：直接旋转扭蛋机按钮，或下拉拉霸机拉杆，先随机获得专注时长，再选择提醒开始。本次时长保留随机结果，不按随后选择的提醒安排时长重新调整。
长按时保持不动；旋转或下拉时持续移动，避免两种手势混淆。

## 项目与提醒

在项目文件夹页面：
- 点击右下角 **＋** 添加项目。
- 长按文件夹，编辑或删除项目。
- 点击文件夹，查看项目中的提醒便签。

在提醒便签页面：
- 点击右下角 **＋** 添加提醒。
- 左右滑动，切换查看提醒。
- 长按便签，修改提醒内容。
- 向上滑动便签，将该提醒标记为完成。

## 日历与专注记录

### 月视图

月视图展示提醒事项。点击提醒前的番茄标记，可以切换完成状态。支持双指放大或者缩小页面。
点击想查看的那一周所在行，展开周视图。

### 周视图

周视图展示已经记录的专注时间块。
时间块显示所属项目、开始与结束时间，以及专注时长。点击时间块，可查看关联的提醒任务和详细记录。
双指缩放可以调整时间轴间距。
也可以拖动时间块玩一会儿：里面的小番茄会随拖动滚动、碰撞。松开后，时间块回到原位，不改变原本的记录时间。

## 本地保存与导出

点击日历中的云朵图标，可以选择本地保存位置，或导出 Excel 文件。
当前使用本地保存方式，手机与电脑之间不会自动同步。更换设备或卸载软件前，请先备份数据。
提醒和专注记录合并在「提醒与专注」工作表中，时间列依次为：计划开始时间、计划截止时间、执行开始时间、执行结束时间，方便对照计划与实际执行情况。
同一提醒有多次专注记录时分别列出；尚未执行的提醒保留计划时间，执行时间留空。已删除提醒留下的历史专注记录仍可导出，暂停间隔不会重复计入专注时长。
